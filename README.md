# ⚽ Football Wordle

A football-themed guessing game where players test their knowledge of footballers through clues, guesses, and limited attempts.

## ✨ Features

* ⚽ Guess football players using interactive gameplay
* 🔍 Search and select player names
* 🎯 Limited attempts to identify the correct player
* ⏱️ Timer-based challenge
* 💡 Clues and feedback to guide your guesses
* 🏆 Test your football knowledge and improve your accuracy

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6+)
* Local player data

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/siemg22/Football-Wordle.git
   ```
2. Open the project folder:
   ```bash
   cd Football-Wordle
   ```
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
